# Nollan Play

A responsive, no-sign-up discovery homepage for football coverage, match highlights, movie trailers, and free-to-watch films from official sources.

## Run locally
Open `index.html` in a browser. The site is a static page and does not require a build step, API keys, or a backend.

## Publish with GitHub Pages
1. Open the repository's **Settings**.
2. Select **Pages** from the sidebar.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/(root)`, then save.
5. Wait for GitHub Pages to publish the site. The URL will appear in the Pages settings.

## Content and streaming
This project links to third-party official platforms. It does not host, copy, or rebroadcast streams or movies. Before adding any stream or film, confirm you have permission to link/embed it and that the content is authorized for the intended audience. Third-party services can impose their own ads, accounts, fees, and regional restrictions.

## Customize
Edit the cards and URLs in `index.html`. Only add live stream URLs and film embeds when you have confirmed the relevant rights and provider terms.
